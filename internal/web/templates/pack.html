Sur le poste · {{$d.Platform.Label}}

    {{if and $d.Install $d.Linux}}
  1. Copier le kit sur le poste et le décompresser (le mot de passe, lui, par un autre chemin), puis ouvrir un terminal dans son dossier.
  2. Installer kura-agent (kit seulement ; avec le paquet seul, le .deb est déjà installé) :
    sudo apt install ./kura-agent_*.deb
  3. Installer le poste :
    sudo kura-agent install --package {{$d.File}}
    install demande le mot de passe, installe la CLI AWS si elle manque (signature PGP d'AWS vérifiée), crée le compte kura-agent (lecture seule), range les secrets dans le coffre (systemd-creds), vérifie l'accès au bucket, crée le minuteur kura-sync.timer, puis supprime le paquet.
    4. {{else if $d.Linux}}
  4. Copier le fichier sur le poste (le mot de passe, lui, par un autre chemin).
  5. Dans un terminal (kura-agent 0.7 ou plus récent) :
    sudo kura-agent import /chemin/vers/{{$d.File}}
    L'import essaie la clé auprès de Wasabi avant de remplacer l'ancienne (secret {{$d.CredName}}), puis supprime le fichier.
    6. {{else if $d.Install}}
  6. Copier le kit sur le poste et le décompresser (le mot de passe, lui, par un autre chemin).
  7. Dans une invite de commandes en tant qu'administrateur, depuis le dossier du kit :
    kura-agent.exe install --package {{$d.File}}
    install demande le mot de passe, installe la CLI AWS si elle manque (signature Amazon vérifiée), range les secrets dans le coffre, vérifie l'accès au bucket, crée la tâche planifiée et l'icône, puis supprime le paquet.
    8. {{else}}
  8. Copier le fichier sur le poste (le mot de passe, lui, par un autre chemin).
  9. Dans une invite de commandes en tant qu'administrateur (kura-agent 0.5 ou plus récent) :
    kura-agent import C:\chemin\vers\{{$d.File}}
    L'import essaie la clé auprès de Wasabi avant de remplacer l'ancienne (secret {{$d.CredName}}), puis supprime le fichier.
    10. {{end}} {{if $d.Linux}}
  10. Lancer une sauvegarde (sudo systemctl start --no-block kura-sync.service, suivie par journalctl -u kura-sync.service -f) ou attendre la suivante, et vérifier qu'elle réussit.
    11. {{else}}
  11. Attendre la sauvegarde suivante (ou « Sauvegarder maintenant » depuis l'icône) et vérifier qu'elle réussit.
    12. {{end}}
  12. Revenir sur la page du bucket et cliquer sur Confirmer l'installation : la console désactive alors les anciennes clés qu'elle a créées.

Paquet perdu ou mot de passe oublié : désactiver cette clé sur la page du bucket et en créer une nouvelle.
