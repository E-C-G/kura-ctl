Sur le poste

    {{if $d.Install}}
  1. Copier le kit sur le poste et le décompresser (le mot de passe, lui, par un autre chemin).
  2. Dans une invite de commandes en tant qu'administrateur, depuis le dossier du kit :
    kura-agent.exe install --package {{$d.File}}
    install demande le mot de passe, installe la CLI AWS si elle manque (signature Amazon vérifiée), range les secrets dans le coffre, vérifie l'accès au bucket, crée la tâche planifiée et l'icône, puis supprime le paquet.
    3. {{else}}
  3. Copier le fichier sur le poste (le mot de passe, lui, par un autre chemin).
  4. Dans une invite de commandes en tant qu'administrateur (kura-agent 0.5 ou plus récent) :
    kura-agent import C:\chemin\vers\{{$d.File}}
    L'import essaie la clé auprès de Wasabi avant de remplacer l'ancienne (secret {{$d.CredName}}), puis supprime le fichier.
    5. {{end}}
  5. Attendre la sauvegarde suivante (ou « Sauvegarder maintenant » depuis l'icône) et vérifier qu'elle réussit.
  6. Revenir sur la page du bucket et cliquer sur Confirmer l'installation : la console désactive alors les anciennes clés qu'elle a créées.

Paquet perdu ou mot de passe oublié : désactiver cette clé sur la page du bucket et en créer une nouvelle.
